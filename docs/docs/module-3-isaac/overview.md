# Module 3: Advanced Perception

## Overview

Module 3 focuses on advanced perception using NVIDIA Isaac Sim. Over 4 weeks, you'll learn photorealistic simulation, sensor integration, and perception pipeline deployment.

## Learning Objectives

By the end of this module, you will:

- Deploy perception systems in NVIDIA Isaac Sim
- Integrate Isaac Sim with ROS 2 via official bridges
- Implement vision processing pipelines
- Work with RGB-D cameras, LiDAR, and other sensors
- Prepare datasets for machine learning with domain randomization

## Module Structure

| Week | Focus | Topics |
|------|-------|--------|
| 7 | Isaac Sim Basics | Environment setup, sensor simulation |
| 8 | ROS 2 Bridge | Integration with ROS 2 Humble/Iron |
| 9 | Vision Systems | Camera models, computer vision algorithms |
| 10 | Perception Pipeline | End-to-end perception architectures |

## Prerequisites

- Completion of Modules 1–2
- NVIDIA GPU required (RTX 4060 Ti minimum)
- Docker knowledge beneficial

## Key Deliverables

1. **Week 7–8**: ROS 2 + Isaac Sim integration
2. **Week 9–10**: Complete perception pipeline with sensor fusion
