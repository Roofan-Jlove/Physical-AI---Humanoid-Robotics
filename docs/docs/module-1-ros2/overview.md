# Module 1: ROS 2 Foundations

## Overview

Module 1 introduces the **Robot Operating System 2 (ROS 2) Humble**, the foundational framework for modern robotics. Over 2 weeks, you'll master core ROS 2 concepts and build your first distributed robotic applications.

## Learning Objectives

By the end of this module, you will:

- Understand ROS 2 architecture and the publish-subscribe paradigm
- Create and configure ROS 2 nodes in Python and C++
- Implement communication patterns: topics, services, and actions
- Use ROS 2 launch files for multi-node orchestration
- Debug ROS 2 applications with command-line tools

## Module Structure

| Week | Focus | Topics |
|------|-------|--------|
| 1 | ROS 2 Introduction | Architecture, Installation, First Node |
| 2 | Communication Patterns | Topics, Services, Actions |

## Prerequisites

- Basic Linux/Ubuntu command line skills
- Familiarity with Python or C++
- Ubuntu 22.04 LTS system (or Jetson Orin running Ubuntu 22.04)

## Hardware Requirements

- **Workstation**: Ubuntu 22.04 LTS (no GPU required for Weeks 1–2)
- **Jetson Orin**: Optional for Week 2 deployment testing

## Key Deliverables

1. **Week 1**: First ROS 2 node communicating via topics
2. **Week 2**: Multi-node system using topics, services, and actions
