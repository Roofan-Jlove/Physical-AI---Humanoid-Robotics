# Physical AI & Humanoid Robotics

## Introduction

Welcome to the **Physical AI & Humanoid Robotics** curriculum, a comprehensive guide to building autonomous humanoid robots using modern robotics frameworks, simulation environments, and cutting-edge AI systems.

### Learning Arc

This 13-week curriculum is organized into 4 progressive modules, each building upon foundational concepts:

1. **Module 1: ROS 2 & Robotics Foundations** (Weeks 1–2)
   - Master the Robot Operating System 2 (ROS 2) Humble
   - Understand core robotics concepts: nodes, topics, services, actions
   - Build your first ROS 2 applications

2. **Module 2: Gazebo & Unity Digital Twin Simulation** (Weeks 3–6)
   - Simulate robots in Gazebo, the open-source physics simulator
   - Learn digital twin architecture
   - Explore Unity Robotics for advanced visualization

3. **Module 3: NVIDIA Isaac & Advanced Perception** (Weeks 7–10)
   - Deploy perception pipelines using NVIDIA Isaac Sim
   - Integrate vision systems with ROS 2
   - Train models with photorealistic simulation

4. **Module 4: Vision-Language-Action (VLA) Systems** (Weeks 11–13)
   - Implement end-to-end VLA models for robotic control
   - Bridge language understanding with robotic actions
   - Build autonomous humanoid workflows

### Capstone Project: Autonomous Humanoid Pipeline

Across all modules, you'll build toward a 5-stage capstone pipeline:

- **Voice Input** → Natural language commands for humanoid robots
- **Planning** → Goal decomposition and task planning
- **Navigation** → Autonomous movement in complex environments
- **Perception** → Visual scene understanding
- **Manipulation** → Grasping and executing tasks

### Hardware & Prerequisites

This curriculum is designed for:

- **Workstations**: Ubuntu 22.04 LTS + NVIDIA GPU (RTX 4060 Ti or equivalent)
- **Edge Devices**: NVIDIA Jetson Orin series for deployment
- **Humanoid Robots**: Boston Dynamics Atlas, Tesla Bot, or open-source alternatives

> **For Jetson Orin Users**: See the [Hardware Setup](hardware-setup/jetson-setup.md) guide for environment configuration.

### Constitutional Principles

This curriculum adheres to 5 core principles:

1. **Technical Accuracy** — All code and documentation validated against official specifications
2. **Clarity & Accessibility** — Complex concepts explained with examples and analogies
3. **Consistency** — Uniform terminology, formatting, and code style throughout
4. **Practicality** — Hands-on examples that work with standard hardware
5. **Traceability** — Every claim linked to authoritative sources
