# Week 6: Digital Twin Architecture & Sim-to-Real

## Overview

Digital twins mirror real robots in simulation. This week covers designing digital twin systems for seamless sim-to-real transfer.

## Learning Objectives

- Understand digital twin architecture
- Implement sim-to-real workflows
- Validate simulation fidelity
- Handle domain randomization

## Architecture Pattern

Simulation ↔ ROS 2 Bridge ↔ Real Robot

## Domain Randomization

Variation in simulation improves real-world robustness:
- Physics parameters
- Sensor noise
- Visual appearance
- Environmental factors

## Exercises

1. Create matching Gazebo + Real robot control stack
2. Test sim-to-real transfer
3. Compare simulation vs. real behavior
