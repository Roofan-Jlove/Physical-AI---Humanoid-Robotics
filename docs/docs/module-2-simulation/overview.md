# Module 2: Simulation & Digital Twins

## Overview

Module 2 introduces robot simulation using Gazebo and Unity. Over 4 weeks, you'll build digital twin representations of robots and learn to simulate complex robotic systems before deploying to hardware.

## Learning Objectives

By the end of this module, you will:

- Understand URDF (Unified Robot Description Format) and SDF (Simulation Description Format)
- Create and simulate robot models in Gazebo
- Integrate ROS 2 with Gazebo for end-to-end control
- Explore Unity Robotics for advanced visualization
- Design and implement digital twin architectures

## Module Structure

| Week | Focus | Topics |
|------|-------|--------|
| 3 | Gazebo Basics | Installation, simulation environment, basic models |
| 4 | URDF & SDF | Robot description formats, creating custom robots |
| 5 | Unity Robotics | 3D visualization, optional advanced track |
| 6 | Digital Twin | Architecture patterns, sim-to-real workflows |

## Prerequisites

- Completion of Module 1 (ROS 2 Foundations)
- Basic understanding of robot kinematics
- Ubuntu 22.04 LTS with NVIDIA GPU (RTX 4060 Ti or equivalent recommended)

## Key Deliverables

1. **Week 3–4**: Fully simulated robot model in Gazebo
2. **Week 5**: Optional Unity visualization pipeline
3. **Week 6**: Digital twin system with ROS 2 integration
