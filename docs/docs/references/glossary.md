# Glossary

## Robotics Fundamentals

**Action**: Long-running ROS 2 task with feedback messages (e.g., navigation, grasping).

**Affordance**: Physical property of an object indicating how it can be manipulated (e.g., a handle is graspable).

**DDS (Data Distribution Service)**: Middleware layer used by ROS 2 for distributed communication.

**End-to-End Learning**: Training neural networks to map raw sensors directly to motor commands.

**Kinematics**: Study of motion without considering forces; forward/inverse kinematics for robots.

**Node**: Independent process in ROS 2 that publishes/subscribes to topics or provides/requests services.

**Service**: Synchronous ROS 2 communication pattern (request-response).

**Topic**: Asynchronous ROS 2 communication channel where nodes publish and subscribe to messages.

**Trajectory**: Path through robot configuration space over time.

**URDF**: Unified Robot Description Format; XML standard for describing robot structure.

## AI/ML Terms

**LLM (Large Language Model)**: Neural network trained on vast text data (e.g., GPT, Gemini).

**SFT (Supervised Fine-Tuning)**: Training approach for language models.

**Transformer**: Neural network architecture using attention mechanisms; foundation of modern LLMs.

**VLA (Vision-Language-Action)**: End-to-end model combining vision, language, and robotics.

**ViT (Vision Transformer)**: Transformer applied to computer vision tasks.

## Hardware Terms

**GPU**: Graphics Processing Unit; accelerates deep learning and simulation.

**Jetson Orin**: NVIDIA's edge AI processor for robotics applications.

**LPDDR5**: Low-Power Double Data Rate memory; used in embedded systems.

**RTX**: Real-Time ray-tracing GPU technology from NVIDIA.
