# Student Navigation Guide

Welcome to the Physical AI & Humanoid Robotics curriculum! This guide will help you navigate the course and make the most of your learning experience.

## Your Learning Journey

```
Week 1-2: ROS 2 Foundations
    ↓ (You learn distributed robotics systems)
Week 3-6: Simulation & Digital Twins
    ↓ (You simulate robots before deployment)
Week 7-10: Advanced Perception
    ↓ (You build visual understanding systems)
Week 11-13: VLA & Autonomous Workflows
    ↓ (You enable language-controlled robots)
Final: Capstone Project
    ↓ (You build an end-to-end autonomous system)
```

## How to Use This Curriculum

### Start Here: Module 1 (Weeks 1-2)
- **What You'll Learn**: Robot Operating System 2 (ROS 2), the middleware that connects all robots
- **Time Commitment**: 6-8 hours total
- **Hardware Needed**: Ubuntu 22.04 Linux workstation (no GPU required)
- **What Success Looks Like**: You create a ROS 2 node that publishes messages

👉 **Start with [Week 1: ROS 2 Introduction](/docs/module-1-ros2/week-1-intro)** if you're new to robotics

---

## Module-by-Module Roadmap

### Module 1: ROS 2 Foundations (Weeks 1-2)
**Foundation** for all subsequent modules
- Week 1: ROS 2 architecture, installation, first node (publisher)
- Week 2: Services, actions, multi-node systems, launch files

**You Need**: Linux basics, Python familiarity

**Time**: 6-8 hours

**Next**: Module 2

---

### Module 2: Simulation & Digital Twins (Weeks 3-6)
**Prerequisite**: Complete Module 1
- Week 3: Gazebo physics simulator, world files
- Week 4: URDF/SDF robot description formats
- Week 5: Unity Robotics visualization (optional)
- Week 6: Digital twin architecture, sim-to-real

**You Need**: GPU recommended (RTX 4060 Ti or equivalent)

**Time**: 16-20 hours

**Next**: Module 3

---

### Module 3: Advanced Perception (Weeks 7-10)
**Prerequisite**: Complete Modules 1-2
- Week 7: NVIDIA Isaac Sim, photorealistic sensors
- Week 8: ROS 2 bridge, sensor data integration
- Week 9: Vision systems, computer vision algorithms
- Week 10: Multi-sensor fusion, end-to-end pipelines

**You Need**: NVIDIA GPU (RTX 4060 Ti or Jetson Orin)

**Time**: 18-22 hours

**Next**: Module 4

---

### Module 4: Vision-Language-Action Systems (Weeks 11-13)
**Prerequisite**: Complete Modules 1-3
- Week 11: VLA model architectures, state-of-the-art
- Week 12: Natural language grounding, speech recognition
- Week 13: End-to-end autonomous workflows

**You Need**: GPU, API access (OpenAI, Google, or local LLM)

**Time**: 15-18 hours

**Next**: Capstone Project

---

## Capstone Project: Build an Autonomous Humanoid Robot

After completing all 4 modules, you'll integrate everything into a **5-stage autonomous pipeline**:

1. **Voice Input**: Accept natural language commands ("Pick up the cup")
2. **Planning**: Decompose goals into robot actions
3. **Navigation**: Move to task locations
4. **Perception**: Understand visual scenes and object locations
5. **Manipulation**: Grasp and manipulate objects

**Capstone Duration**: 2-4 weeks (depending on depth)

**Deliverables**:
- Working system (simulation + real robot if available)
- Video demonstration
- Technical report

## Getting Help

### If You Get Stuck:

1. **Check Troubleshooting Sections**: Each module has a troubleshooting guide
2. **Search References**: Glossary and citations for definitions
3. **Ask on ROS Discourse**: https://discourse.ros.org/
4. **Check GitHub Issues**: https://github.com/your-repo/issues

### Common Questions:

**Q: Do I need prior robotics experience?**
- A: No! This curriculum starts from fundamentals. Linux + Python basics are enough.

**Q: Can I skip modules?**
- A: Not recommended. Module 1 is required. For fast-track, see instructor options.

**Q: What if I don't have a GPU?**
- A: Modules 1-2 work on CPU. Modules 3-4 need GPU or cloud access.

**Q: How long does the full curriculum take?**
- A: ~65 hours spread over 13 weeks (5 hours/week avg)

## Success Tips

1. **Follow the sequence**: Don't skip to Module 4 without Module 1 foundation
2. **Do the exercises**: Hands-on learning is critical
3. **Engage with code**: Modify examples, break things, learn
4. **Connect concepts**: Each module builds on the previous
5. **Join communities**: ROS Discourse, GitHub discussions, peer groups
